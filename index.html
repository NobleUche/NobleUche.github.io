02 — Method

Hand, then code, then software.

Engineering software is only useful if it is correct. So every topic I learn goes through the same three checks.

Solve it by hand

Free-body diagram, equations, a number with units. If I cannot do it on paper, I do not yet understand it.

M = r × F

Verify it in code

Write a tested Python function and compare it with the hand result and the textbook answer.

np.cross(r, F)

Check it with simulation

Build the same model in PrePoMax and CalculiX, then compare. Agreement builds trust. Disagreement teaches me something.

K u = F

The goal is a tool whose tests cite their source: a hand calculation, a textbook example, or a simulation result.
